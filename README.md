# Clash Tracker

Локальное приложение для Windows. Помогает главе клана Clash of Clans учитывать донат за выбранный период, объединять несколько аккаунтов одного игрока и выгружать результаты в Excel.

Можно скачать и использовать приложение для учёта статистики своего клана.

## Запуск на Windows

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/windows/) с компонентом Tcl/Tk. Для запуска приложения сторонние библиотеки не нужны.
2. В репозитории нажмите **Code → Download ZIP** и распакуйте архив.
3. Запустите `Start_Windows.bat`. Можно также запустить `python app.py` из папки проекта.
4. Создайте свой ключ на [портале разработчиков Supercell](https://developer.clashofclans.com/). В приложении откройте **Настройки**, вставьте ключ и выберите способ подключения.

| Подключение | Как настроить ключ |
| --- | --- |
| Напрямую к Supercell | Добавьте в разрешённые IP свой внешний IP-адрес. При его изменении обновите ключ. |
| RoyaleAPI Proxy | Добавьте в разрешённые IP адрес прокси, указанный в настройках приложения. Запросы и ключ передаются этому прокси по HTTPS. |

Используйте ключ разработчика. Игровой токен из профиля Clash of Clans для этого не подходит.

## Учёт доната и ЛВК

1. Создайте игрока и добавьте его аккаунты по игровым тегам.
2. Нажмите **Начать подсчёт для всех**, чтобы записать начальные значения достижения **«Настоящий друг»** (Friend in Need).
3. Обновляйте данные кнопкой **Пересчитать всё**. Донат за период считается как прирост достижения. Для аккаунта, добавленного посреди периода, учёт начинается с момента добавления.
4. Нажмите **Завершить и сохранить Excel**, чтобы зафиксировать итог периода и получить общий отчёт.
5. Для ЛВК укажите теги кланов в настройках. Звёзды считаются по атакам в доступных войнах текущего сезона. Если API вернул часть войн, сумма может быть неполной.

## Отчёты Excel

| Действие | Результат |
| --- | --- |
| Открыть отчёты | Открывает настроенную папку. По умолчанию это `Документы\ClashTracker`. |
| Пересчитать всё | Обновляет статистику без создания файла. |
| Сохранить Excel | Создаёт один файл в выбранной папке. Для открытого периода имя заканчивается на `_snapshot.xlsx`, для закрытого — на `_final-copy.xlsx`. |
| Завершить и сохранить Excel | Закрывает период и создаёт один файл `_final.xlsx` в настроенной папке. |

В имени файла указываются дата и время по Москве и номер периода, если он есть. В отчёте есть итоги по игрокам, детализация по аккаунтам и журнал. Из **Истории периодов** можно снова выгрузить закрытый период.

## Хранение и ограничения

- Игроки, периоды и история хранятся в `%LOCALAPPDATA%\ClashTracker\tracker.sqlite3`. Резервную копию базы можно сделать в настройках.
- Ключ хранится локально в `%LOCALAPPDATA%\ClashTracker\settings.json`. Этот файл содержит секрет и не предназначен для публикации.
- Используйте одно окно приложения для каждой базы. В версии 0.9 одновременные пересчёт, завершение и экспорт в разных окнах могут привести к расхождениям между базой и отчётом.

## Тесты

```powershell
python -m pip install openpyxl
python -m unittest discover -v
```

Для тестов интерфейса требуется графический рабочий стол. Тесты выполняются на тестовых данных и не требуют ключа API.
